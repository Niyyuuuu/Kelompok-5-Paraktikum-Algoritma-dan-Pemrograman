# Kelompok-5-Paraktikum-Algoritma-dan-Pemrograman

# Analisis Karakteristik Harga Rumah (Housing) - Kelompok 5

Repository ini berisi hasil pengerjaan post test Praktikum Algoritma dan Pemrograman 2026 untuk Kelas C, Kelompok 5. Dataset yang digunakan adalah `Kelas C_Housing.csv` (berisi 545 baris dan 13 kolom data), dengan fokus analisis pada faktor-faktor yang memengaruhi harga rumah seperti luas tanah, jumlah kamar, fasilitas (AC, jalan utama, basement), dan status kelengkapan furnitur.
